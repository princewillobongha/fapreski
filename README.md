# FAPRESKI — Starter Website

This is the first working front-end prototype for FAPRESKI, "Movies at Your Fingertips".

## Included now
- FAPRESKI logo
- Responsive streaming-style homepage
- Clickable movie cards
- Working Watch Now modal/player
- New Releases and Trending sections
- Categories
- My List, Messages, Sign In and 7-day trial buttons
- Mobile-friendly layout

## Important
The player currently uses a freely available demo video only to prove that the player works. It is NOT a catalogue of commercial movies.

Before a public commercial launch, connect:
1. Authorized movie/content licensing
2. A production video delivery/DRM provider
3. Real movie metadata API under its commercial terms
4. Authentication (Google + email)
5. Subscription/payment provider
6. Database/backend
7. Moderation/reporting tools
8. Multilingual localization

## Run
Open `index.html` in a browser. For best results, serve the folder from a local web server or deploy it to a static host.
